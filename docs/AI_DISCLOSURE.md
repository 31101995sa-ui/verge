# AI Assistance Disclosure

**Project:** VERGE — NASA Edition / Stellar Anvil
**Challenge:** NASA Space Apps Challenge 2026 — Flame in Freefall
**Date:** 14 November 2026

The project has **one human participant**. OpenAI **ChatGPT (GPT-6)** served as an AI-assisted research and software-development tool, **not** as a registered or human team member.

## What AI assisted with

- Technical planning and architecture sketches for the scientific evidence workflow.
- Drafting Python application code and automated tests under human review.
- Drafting UI language translations and English-language documentation.
- Source-discovery, data-quality and scientific-restriction checklist preparation.
- Explaining errors and proposing debugging and reproducibility steps.

## What was checked by the human developer

The human participant selected the scope, reviewed and applied changes, ran local Python and browser checks, and retained responsibility for final scientific statements and submission. Observed benchmarks are recorded as test outputs; they are **not** independent experimental validation of physical behavior.

Scientific values were transcribed and audited against original NASA reports under NASA-DAP protocols. Published values are not invented or supplied as uncited LLM facts. NASA-EVP verdicts are issued by deterministic application logic against released source data, not by a language model assessing its own answer.

## Runtime implementation

**No live LLM API, external chat model or autonomous agent is integrated into the current dashboard.** The only text-to-structured-claim conversion is a narrow, English-only rule-based Table IX parser requiring human confirmation. The public application can run without AI API credentials.

If a bounded source-grounded LLM adapter is added later, its generated output must be explicitly identified, source-linked and independently checked, with an API-free deterministic fallback and no safety-certification claims.

## Where to disclose

Include the AI assistance above in the NASA project submission's tools/resources section, the repository README and any presentation describing the development process. Any AI-generated media will require separate provenance and usage notices.
